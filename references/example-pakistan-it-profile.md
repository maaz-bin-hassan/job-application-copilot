# Example Pakistan IT Search Profile

Use this only as a starter when the user requests a Pakistan-focused IT job search. Adapt it to the candidate instead of silently assuming it applies.

```text
Target roles:
- cross-platform mobile app developer
- React Native developer
- Flutter developer
- frontend developer
- web developer
- software QA, QA engineer, QA analyst, software tester, or SDET

Role priority:
1. Cross-platform mobile app developer
2. React Native developer
3. Flutter developer
4. Frontend developer
5. Web developer
6. Software QA roles

Minimum experience:
- Prefer listings requiring at least 1 year of experience.
- Keep listings where the experience requirement is unknown, but mark the uncertainty.

Recency:
- Prefer roles posted within the last 24 hours when posting time is available.

Allowed onsite locations:
- Islamabad
- Rawalpindi
- nearby Islamabad and Rawalpindi areas
- Lahore
- Sukkur

Allowed hybrid locations:
- Islamabad
- Rawalpindi
- nearby Islamabad and Rawalpindi areas
- Lahore
- Sukkur

Remote roles:
- Allow remote roles from any country.

Excluded locations:
- Exclude Karachi and other unlisted locations for onsite and hybrid roles.

Preferred sources:
- LinkedIn
- Indeed
- employer career pages
- banks, software houses, startups, universities, and IT-related employers

Daily draft limit:
- Maximum 10 strong, eligible, non-duplicate roles.
```
